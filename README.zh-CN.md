## 站点边界

本仓库用于组织主页和公共资源，保留未来其他 Teloa 项目使用根入口的空间。GitHub Pages 从 main 根目录发布，使用 teloa-ai.github.io，不绑定自定义域名。

安全门户使用独立的 [security-site 仓库](https://github.com/teloa-ai/security-site)，通过 Cloudflare Pages 发布到 security.teloa.ai。门户的 /agent-baseline-assessor/ 路径仅承载固定公开版本的演示。基线是可自行部署的独立开源项目，其 GitHub Pages 发布与组织主页分离。

默认语言为英文，?lang=zh-CN 可切换简体中文。站点采用静态 HTML 与本地资源，无分析追踪或数据收集。

安全问题请参考[报告指引](https://security.teloa.ai/report/?lang=zh-CN)，或联系 [security@teloa.ai](mailto:security@teloa.ai)。品牌素材权利说明见 [assets/README.md](assets/README.md)。
