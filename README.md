## Site boundaries

This repository keeps the organization homepage and shared public assets available for Teloa. It publishes from the root of main at teloa-ai.github.io, without a custom domain.

The security portal uses the separate [security-site repository](https://github.com/teloa-ai/security-site) and Cloudflare Pages at security.teloa.ai. Its /agent-baseline-assessor/ route hosts a demo assembled from a reviewed public project revision. The baseline remains an independent, self-hostable open-source project; its own GitHub Pages deployment is separate from this organization site.

English is the default. Use ?lang=zh-CN for Simplified Chinese. The site uses static HTML and local assets, without analytics or data collection.

For security reports, follow the [reporting guidance](https://security.teloa.ai/report/) or contact [security@teloa.ai](mailto:security@teloa.ai). Brand asset rights are described in [assets/README.md](assets/README.md).
